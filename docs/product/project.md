# Projeto — Manga Archive Manager

## Nome

Manga Archive Manager (MAM)

## Tipo

Aplicação desktop multiplataforma portátil

## Público-alvo

Usuários que desejam gerenciar uma biblioteca própria de mangás e quadrinhos digitais armazenada em SSD externo, acessível em diferentes computadores (Windows e Linux).

## Restrições

- Processamento de IA exclusivamente local
- Não depender de servidor remoto ou banco de dados pré-instalado
- Não exigir instalação convencional obrigatória
- Permitir execução a partir de diferentes unidades de armazenamento
- Preservar portabilidade de dados e configurações

## Hardware mínimo de referência

| Componente | Referência |
|------------|------------|
| CPU | Intel Core i7-6700K (4c/8t, 4,00 GHz) |
| RAM | 16 GB DDR4 |
| GPU | AMD Radeon RX 7600 (8 GB VRAM) |
| Arquitetura | x86-64 |
| Armazenamento | SSD |

## Distribuição

- Windows: pacote portátil ZIP
- Linux: AppImage (prioritário), TAR.GZ (alternativa)
