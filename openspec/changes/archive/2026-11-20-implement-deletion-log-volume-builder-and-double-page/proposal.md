# Proposta: Log de Exclusões, Exclusão de Obras, Montagem/Renomeação de Volumes e Capítulos, e Double Page 50/50

## Resumo
1. Registrar exclusões de capítulos e obras no histórico (`tipo = 'exclusao'`) e exibir o Log de Exclusões na interface.
2. Permitir excluir obras inteiras da Biblioteca (banco + arquivos).
3. Permitir selecionar capítulos para formar volumes com número de ordem e nome, renomear volumes e renomear títulos de capítulos baixados.
4. Corrigir o modo Double Page no leitor (`CbzReader`) para dividir exatamente 50% / 50% entre as duas páginas.
